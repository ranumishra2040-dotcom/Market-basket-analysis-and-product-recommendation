# Dataset Source

The dataset used in this project is a retail transaction basket dataset.

* **Source**: User provided Google Drive link
* **Link**: [Google Drive Folder](https://drive.google.com/drive/folders/1XC-00liRViTlyeFaig3mYTkQcBrheph6?usp=sharing)
* **File Used**: `part_2_market_basket_analysis.csv`
* **Features**:
  * `TransactionID`: A unique identifier for each transaction
  * `CustomerID`: A unique identifier for the customer
  * `TransactionDate`: Date of the transaction
  * `ProductID`: A unique identifier for each product
  * `ProductName`: The name of the product
  * `Quantity`: The quantity purchased
  * `UnitPrice`: The price of the product
